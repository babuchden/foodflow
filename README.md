# FoodFlow — АІС управління доставкою готової їжі

Навчальна настільна інформаційна система для керування замовленнями доставки готової їжі.

## Можливості

- інформаційна панель з показниками за день;
- створення замовлень із декількох позицій меню;
- автоматичний розрахунок суми замовлення;
- база клієнтів;
- база кур'єрів і контроль їхнього статусу;
- призначення кур'єра на замовлення;
- зміна статусів замовлення;
- перегляд складу кожного замовлення;
- керування меню та доступністю позицій;
- пошук і фільтрація замовлень;
- локальна реляційна база даних SQLite.

## Технології

- Python 3
- Tkinter / ttk
- SQLite

Сторонні бібліотеки не потрібні.

## Запуск

Windows:

1. Встановити Python 3.
2. Запустити `run.bat` або виконати `python main.py`.
3. База `food_delivery.db` створиться автоматично при першому запуску.

## Структура БД

Основні сутності:

- `customers` — клієнти;
- `couriers` — кур'єри;
- `menu_items` — позиції меню;
- `orders` — замовлення;
- `order_items` — склад замовлень.

Між таблицями використані зовнішні ключі. Один клієнт може мати багато замовлень, одне замовлення може містити багато позицій меню, кур'єр може бути призначений до замовлення.

## Логіка процесу

Клієнт → Замовлення → Склад замовлення → Приготування → Призначення кур'єра → Доставка → Завершення.

Під час створення замовлення система зберігає клієнта, склад замовлення, суму та призначеного кур'єра. При завершенні або скасуванні доставки кур'єр автоматично отримує статус `Вільний`.
